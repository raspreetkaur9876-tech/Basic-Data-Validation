# Basic Data Validation – Excel Project

## Project Overview
This project demonstrates basic data validation in Microsoft Excel using an employee data-entry sheet.

## Objective
To improve spreadsheet data quality by restricting invalid entries and providing dropdown options.

## Tools Used
- Microsoft Excel

## Features
- Department dropdown list
- Gender dropdown list
- Employment Status dropdown
- Age validation (18–60)
- Salary validation
- Employee ID validation
- Joining Date validation
- Sample employee records

## Dataset
The project includes sample employee records with the following fields:
- Employee ID
- Employee Name
- Department
- Gender
- Age
- Salary
- Joining Date
- Employment Status

## Learning Outcomes
- Understanding Excel Data Validation
- Creating dropdown lists
- Applying numerical and date restrictions
- Improving data accuracy
- Preventing invalid data entry

## Project Deliverables
- Validated Excel template
- Sample employee entries
- Project instructions sheet
